## 跨平台兼容性特性

### 1. 自适应编码（UTF-8/GBK）

**skill_utils.py 提供**：
- `get_system_encoding()` - 自动检测系统编码
- `setup_utf8_io()` - 设置 UTF-8 IO 编码
- `cross_platform_print()` - 跨平台打印
- `cross_platform_input()` - 跨平台输入

**工作原理**：
```python
def get_system_encoding():
    # Windows 系统通常使用 GBK
    if sys.platform == 'win32':
        try:
            encoding = locale.getdefaultlocale()[1]
            if encoding and 'GBK' in encoding.upper():
                return 'gbk'
        except:
            pass
        return 'utf-8'
    # Linux/macOS 通常使用 UTF-8
    else:
        return 'utf-8'
```

### 4. 中文无乱码

**编码处理流程**：
```
用户输入 → 检测编码 → 转换为 UTF-8 → 处理 → 转换回系统编码 → 显示
```

**错误处理**：
```python
def cross_platform_print(text):
    try:
        # 尝试直接打印
        print(text)
    except UnicodeEncodeError:
        # 如果失败，尝试编码后打印
        try:
            encoding = get_system_encoding()
            print(text.encode(encoding, errors='replace').decode(encoding))
        except:
            # 最后手段：替换所有非 ASCII 字符
            safe_text = text.encode('ascii', errors='replace').decode('ascii')
            print(safe_text)
```

## 故障排除

### 问题 1: 中文显示乱码

**症状**：
```
浣犲ソ，涓栫晫！
```

**原因**：
- 控制台编码不是 UTF-8

**解决方法**：
```bash
# Windows
chcp 65001

# Linux/macOS
export PYTHONIOENCODING=utf-8
```

### 问题 2: 输入中文时报错

**症状**：
```
UnicodeDecodeError: 'gbk' codec can't decode byte...
```

**原因**：
- 输入编码与控制台编码不匹配

**解决方法**：
- Skill 已经自动处理，如果仍有问题，检查系统区域设置

### 问题 3: skill_utils 导入失败

**症状**：
```
ImportError: No module named 'skill_utils'
```

**原因**：
- skill_utils.py 不在正确位置

**解决方法**：
- 确保 skill_utils.py 在 `F:\aa\stigmergy-eb-edu\skills\eb-edu\` 目录
- Skill 会自动添加路径并导入
- 如果仍然失败，会使用备用函数
