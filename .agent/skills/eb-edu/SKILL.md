# 跨境电商教育 - 课程体系、教学大纲、实训项目

## Overview
当学生询问跨境电商教育相关操作时，AI自动执行CLI命令并将结果以自然语言返回学生。

## When to Use (触发条件)
- 学生询问如何配置跨境电商教育
- 学生询问跨境电商教育最佳实践
- 学生询问跨境电商教育故障排除

## AI执行模式

### 流程
1. 检测学生意图
2. 确定对应的命令
3. 执行命令
4. 解析输出，用自然语言向学生解释结果

## 前置条件
- Stigmergy CLI已安装
- Python >= 3.8
- 相关依赖已安装

python -c "print('eb-edu 技能可用')"
