## ✅ 实训业务场景对齐

### 商品运营实训

**真实业务场景**：
```
电商公司运营专员工作流程:
1. 市场调研 → 了解竞品情况
2. 商品录入 → 创建商品信息
3. 定价策略 → 制定合理价格
4. 商品上架 → 发布商品销售
5. 数据监控 → 分析销售数据
6. 优化调整 → 提高转化率
```

**实训设计**：
```
eb-edu-train-product-listing:
1. 情境导入 → 你是一家电商公司的运营专员
2. 市场调研 → 分析竞品数据（LLM 引导）
3. 商品录入 → 创建商品信息
4. 定价策略 → 制定价格策略（LLM 引导）
5. 上架确认 → 发布商品
6. 复盘总结 → LLM 点评，能力提升
```

**能力培养**：
- ✅ 市场调研能力
- ✅ 商品录入能力
- ✅ 定价策略能力
- ✅ 上架操作能力
