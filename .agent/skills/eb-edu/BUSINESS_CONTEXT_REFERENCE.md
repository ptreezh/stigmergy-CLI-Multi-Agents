## 商品管理

### 什么是商品？

**商品**是电商平台的核心，指可以在平台上销售的物品。

### 商品属性

| 属性 | 说明 | 示例 |
|------|------|------|
| **商品 ID** | 唯一标识 | prod_123 |
| **标题** | 商品名称 | 2026 夏季新款连衣裙 |
| **描述** | 详细介绍 | 面料、尺码、颜色等 |
| **价格** | 销售价格 | ¥199 |
| **成本** | 采购/生产成本 | ¥80 |
| **库存** | 可用数量 | 100 件 |
| **状态** | 商品状态 | 草稿、已发布、下架 |
| **SKU** | 库存量单元 | TSHIRT-RED-L |

### 商品状态说明

```
草稿 (draft) → 已发布 (published) → 下架 (deleted)
     ↓              ↓                    ↓
  内部可见      前台可见            不可见
```

- **草稿**：商品已创建但未发布，仅后台可见
- **已发布**：商品已上架，前台用户可见可购买
- **下架**：商品已删除，不再销售

### 商品定价策略

#### 1. 成本加成定价

```
售价 = 成本 × (1 + 毛利率)

示例:
成本：¥80
目标毛利率：50%
售价：¥80 × (1 + 50%) = ¥120
```

#### 2. 竞争定价

```
参考竞争对手价格:
- 竞品 A: ¥159
- 竞品 B: ¥199
- 我的价格：¥179（中间价位，有竞争力）
```

#### 3. 心理定价

```
- ¥199 比 ¥200 更有吸引力
- ¥99 比 ¥100 更有吸引力
- 利用消费者心理定价
```

## 订单管理

### 什么是订单？

**订单**是客户购买商品后生成的交易记录。

### 订单属性

| 属性 | 说明 | 示例 |
|------|------|------|
| **订单 ID** | 唯一标识 | order_123 |
| **订单号** | 显示给客户的编号 | ORD-2026-001 |
| **客户** | 下单客户 | 张三 |
| **商品明细** | 购买的商品列表 | 商品 A x 2, 商品 B x 1 |
| **总额** | 订单总金额 | ¥597 |
| **状态** | 订单状态 | 待处理、已发货、已完成 |
| **创建时间** | 下单时间 | 2026-03-30 10:30 |

### 订单状态流转

```
待处理 (pending) → 处理中 (processing) → 已发货 (shipped) → 已完成 (delivered)
       ↓                  ↓                    ↓                    ↓
    客户下单          商家确认             发货出库            客户签收
       ↓                  ↓                    ↓                    ↓
   可取消              可取消              不可取消            不可取消
```

### 订单处理流程

#### 1. 订单确认

- 检查库存是否充足
- 检查客户信息是否完整
- 检查支付是否成功

#### 2. 订单配货

- 根据订单明细拣货
- 检查商品质量
- 打包商品

#### 3. 订单发货

- 选择物流公司
- 填写物流单号
- 更新订单状态为"已发货"

#### 4. 订单完成

- 客户签收
- 确认无误
- 更新订单状态为"已完成"

### 异常订单处理

#### 订单取消

```
场景:
- 客户主动取消
- 缺货无法发货
- 客户信息错误

处理流程:
1. 确认订单状态（待处理/处理中可取消）
2. 检查是否已发货（已发货不可取消）
3. 执行取消操作
4. 退款（如已支付）
5. 恢复库存
```

#### 订单退款

```
场景:
- 商品质量问题
- 发错货
- 客户不满意

退款类型:
- 全额退款
- 部分退款

处理流程:
1. 确认退款原因
2. 确认退款金额
3. 执行退款操作
4. 记录退款原因
```

#### 按消费行为

```
新客户 (首次购买)
   ↓
活跃客户 (多次购买)
   ↓
沉睡客户 (长期未购买)
   ↓

```

```
普通客户 (消费 < ¥1000)
   ↓
VIP 客户 (消费 ¥1000-5000)
   ↓
高级 VIP 客户 (消费 > ¥5000)
```

## 库存管理

### 什么是库存？

**库存**是商家可用于销售的商品数量。

### 库存属性

| 属性 | 说明 | 示例 |
|------|------|------|
| **库存项 ID** | 唯一标识 | inv_123 |
| **商品 ID** | 关联商品 | prod_123 |
| **SKU** | 规格型号 | TSHIRT-RED-L |
| **库存数量** | 可用数量 | 100 件 |
| **已占用** | 已下单未发货 | 10 件 |
| **可用库存** | 实际可销售 | 90 件 |
| **仓库** | 存放位置 | 主仓库 |

### 库存类型

```
总库存 = 可用库存 + 已占用 + 锁定库存

- 可用库存：可销售的数量
- 已占用：客户已下单但未发货的数量
- 锁定库存：因质量问题等被锁定的数量
```

### 库存预警

#### 低库存预警

```
当库存数量 < 安全库存时，触发预警

安全库存计算:
安全库存 = 日均销量 × 补货周期

示例:
日均销量：10 件
补货周期：7 天
安全库存：10 × 7 = 70 件

当库存 < 70 件时，触发预警，需要补货
```

#### 高库存预警

```
当库存数量 > 最高库存时，触发预警

最高库存计算:
最高库存 = 日均销量 × 最高存储周期

示例:
日均销量：10 件
最高存储周期：30 天
最高库存：10 × 30 = 300 件

当库存 > 300 件时，触发预警，需要促销清库存
```

### 库存调整

#### 入库

```
场景:
- 采购入库
- 退货入库
- 调拨入库

操作:
增加库存数量
记录入库原因
```

#### 出库

```
场景:
- 销售出库
- 报损出库
- 调拨出库

操作:
减少库存数量
记录出库原因
```

#### 库存调拨

```
场景:
- 仓库之间调拨
- 店铺之间调拨

操作:
调出仓库减少库存
调入仓库增加库存
```

## 商品上架流程

### 完整流程

```
1. 市场调研 → 2. 选品 → 3. 采购 → 4. 商品信息准备 → 
5. 商品录入 → 6. 定价 → 7. 上架 → 8. 推广
```

### 第一步：市场调研

**目标**：了解市场需求和竞争情况

**工作内容**:
1. 分析目标用户需求
2. 调研竞争对手商品
3. 分析价格区间
4. 评估市场容量

**使用 Skills**:
- `eb-edu-medusa-list-products` - 查看竞品
- `eb-edu-medusa-sales-analytics` - 分析销售数据

### 第二步：选品

**目标**：选择有市场潜力的商品

**选品标准**:
- 市场需求大
- 竞争相对小
- 利润空间足
- 供应链稳定

### 第三步：采购

**目标**：确保商品供应

**工作内容**:
1. 寻找供应商
2. 谈判价格和条款
3. 下订单采购
4. 质量检验

### 第四步：商品信息准备

**目标**：准备完整的商品信息

**需要准备**:
- 商品标题（吸引眼球）
- 商品描述（详细介绍）
- 商品图片（清晰美观）
- 商品规格（尺码、颜色等）

### 第五步：商品录入

**目标**：将商品信息录入系统

**使用 Skills**:
- `eb-edu-medusa-create-product-guided` - 创建商品（引导式）
- `eb-edu-medusa-create-product` - 创建商品（快速）

### 第六步：定价

**目标**：制定合理的价格

**定价考虑**:
- 成本（采购成本、运营成本）
- 竞品价格
- 目标毛利率
- 用户接受度

### 第七步：上架

**目标**：商品上架销售

**操作**:
- 更新商品状态为"已发布"
- 设置库存数量
- 确认价格正确

**使用 Skills**:
- `eb-edu-medusa-update-product` - 更新商品状态

### 第八步：推广

**目标**：提高商品曝光和销量

**推广方式**:
- 平台内推广（直通车、钻展）
- 社交媒体推广
- 优惠活动
- 优惠券

**使用 Skills**:
- `eb-edu-medusa-create-discount` - 创建优惠券

## 订单处理流程

### 完整流程

```
1. 客户下单 → 2. 订单确认 → 3. 配货 → 4. 打包 → 
5. 发货 → 6. 物流跟踪 → 7. 签收 → 8. 完成
```

### 第一步：客户下单

**触发**：客户在平台下单并支付

**系统自动**:
- 生成订单
- 扣减库存
- 发送订单确认邮件/短信

### 第二步：订单确认

**目标**：确认订单信息无误

**检查项**:
- 商品信息（是否有货）
- 客户信息（地址、电话）
- 支付状态（是否已支付）

**使用 Skills**:
- `eb-edu-medusa-list-orders` - 查看待处理订单
- `eb-edu-medusa-get-order` - 查看订单详情

### 第三步：配货

**目标**：根据订单明细拣货

**工作内容**:
1. 打印拣货单
2. 按单拣货
3. 核对商品

### 第四步：打包

**目标**：安全包装商品

**工作内容**:
1. 选择合适包装
2. 放入商品
3. 放入发货单
4. 封箱打包

### 第五步：发货

**目标**：交付物流公司

**工作内容**:
1. 选择物流公司
2. 填写物流单
3. 更新订单状态

**使用 Skills**:
- `eb-edu-medusa-fulfill-order` - 订单发货

### 第六步：物流跟踪

**目标**：跟踪物流状态

**工作内容**:
1. 查询物流信息
2. 处理物流异常
3. 通知客户物流状态

### 第七步：签收

**目标**：客户签收商品

**工作内容**:
1. 客户确认收货
2. 处理退换货（如有问题）

### 第八步：完成

**目标**：订单完成

**工作内容**:
1. 更新订单状态为"已完成"
2. 记录客户评价
3. 售后服务跟进

**使用 Skills**:
- `eb-edu-medusa-update-order` - 更新订单状态

## 销售分析

### 核心指标

| 指标 | 计算公式 | 说明 |
|------|---------|------|
| **销售额** | 单价 × 销量 | 销售总收入 |
| **销量** | 销售数量 | 卖出的商品数量 |
| **毛利率** | (销售额 - 成本) / 销售额 × 100% | 利润空间 |
| **客单价** | 销售额 / 订单数 | 平均每单金额 |
| **转化率** | 下单人数 / 访问人数 × 100% | 转化效率 |

### 销售趋势分析

```
按时间分析:
- 日销售趋势
- 周销售趋势
- 月销售趋势
- 年销售趋势

用途:
- 发现销售规律
- 预测未来销售
- 制定销售目标
```

### 商品销售分析

```
分析维度:
- 畅销商品（销量 TOP 10）
- 滞销商品（销量 BOTTOM 10）
- 高毛利商品
- 低毛利商品

用途:
- 优化商品结构
- 制定促销策略
- 调整采购计划
```
