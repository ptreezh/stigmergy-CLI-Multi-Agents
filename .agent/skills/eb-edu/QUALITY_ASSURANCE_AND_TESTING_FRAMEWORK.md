## 实训业务场景对齐

### 商品运营实训

**真实业务场景**：

```
电商公司运营专员工作流程:
1. 市场调研 → 了解竞品情况
2. 商品录入 → 创建商品信息
3. 定价策略 → 制定合理价格
4. 商品上架 → 发布商品销售
5. 数据监控 → 分析销售数据
6. 优化调整 → 提高转化率
```

**实训设计**：

```
eb-edu-train-product-listing:
1. 情境导入 → 你是一家电商公司的运营专员
2. 市场调研 → 分析竞品数据（LLM 引导）
3. 商品录入 → 创建商品信息
4. 定价策略 → 制定价格策略（LLM 引导）
5. 上架确认 → 发布商品
6. 复盘总结 → LLM 点评，能力提升
```

**能力培养**：
- ✅ 市场调研能力
- ✅ 商品录入能力
- ✅ 定价策略能力
- ✅ 上架操作能力

**评估标准**：
- ✅ 过程评估（LLM 实时反馈）

## 测试用例设计

### CLI 命令测试用例

**正常场景**：
```bash
# 测试 1: 查看商品列表
stigmergy skill call eb-edu-medusa-list-products
预期：返回商品列表

# 测试 2: 查看商品详情
stigmergy skill call eb-edu-medusa-get-product --product-id "prod_123"
预期：返回商品详情

# 测试 3: 更新商品价格
stigmergy skill call eb-edu-medusa-update-product --product-id "prod_123" --price 199
预期：更新成功
```

**错误场景**：
```bash
# 测试 1: 商品不存在
stigmergy skill call eb-edu-medusa-get-product --product-id "prod_999"
预期：返回错误"商品不存在"

# 测试 2: 价格为负数
stigmergy skill call eb-edu-medusa-update-product --product-id "prod_123" --price -100
预期：返回错误"价格不能为负数"

# 测试 3: 缺少必需参数
stigmergy skill call eb-edu-medusa-update-product --product-id "prod_123"
预期：返回错误"至少需要一个更新参数"
```

**边界条件**：
```bash
# 测试 1: 页码边界
stigmergy skill call eb-edu-medusa-list-products --page 0
预期：返回错误"页码必须大于 0"

# 测试 2: 每页数量边界
stigmergy skill call eb-edu-medusa-list-products --limit 0
预期：返回错误"每页数量必须在 1-100 之间"

# 测试 3: 每页数量上限
stigmergy skill call eb-edu-medusa-list-products --limit 101
预期：返回错误"每页数量必须在 1-100 之间"
```

## 质量检查清单

### CLI 命令质量检查

- [ ] **Shebang 声明** - `#!/usr/bin/env node`
- [ ] **帮助信息** - `--help` 参数支持
- [ ] **参数解析** - 使用 args 解析
- [ ] **错误处理** - try-catch + 有意义的错误信息
- [ ] **API 调用** - 正确的 API 路径和方法
- [ ] **输出格式** - JSON 或格式化文本
- [ ] **退出码** - 成功 0，失败 1

### Skill 质量检查

**skill.json**:
- [ ] name（小写 + 连字符）
- [ ] version（语义化）
- [ ] description（清晰简洁）
- [ ] author（作者/团队）
- [ ] category（类别）
- [ ] tags（至少 1 个标签）
- [ ] triggers（keywords + patterns）
- [ ] parameters（完整 JSON Schema）
- [ ] execution（runtime, script, timeout）
- [ ] permissions（roles, requires_auth）
- [ ] examples（至少 3 个，含 output）
- [ ] errors（错误定义，含 solution）
- [ ] help（short + long）
- [ ] business_context（concept + use_cases + best_practices）

**skill.py**:
- [ ] Shebang 声明
- [ ] 文档字符串
- [ ] build_command 函数
- [ ] execute_command 函数
- [ ] format_output 函数
- [ ] main 函数
- [ ] 错误处理

### 实训教学 Skill 质量检查

- [ ] **LLM 智能引导** - 完整的引导式学习流程
- [ ] **业务背景知识** - 概念、指南、案例
- [ ] **渐进式披露** - 参数分层、示例分级、输出分层
- [ ] **实训任务完整** - 目标、内容、评估
- [ ] **专业能力培养** - 明确的培养目标
- [ ] **真实场景对齐** - 对应真实工作岗位
- [ ] **能力评估标准** - 明确的评估标准
