# 认知陷阱平台开发专家技能

## 概述

认知陷阱平台开发专家技能为《失败的逻辑》理论教育平台提供专业开发指导。该技能整合了认知偏差教育、指数增长理解、系统思维训练等领域的专业知识。

## 专业领域

### 1. 认知偏差教育设计
- **指数增长误区纠正**: 设计教学内容纠正人类对指数增长的线性思维误区
- **复利思维训练**: 构建复利效应的反直觉特性理解
- **历史决策案例**: 重现挑战者号等历史决策失败案例的教学场景
- **推理游戏设计**: 创建挑战思维局限的互动游戏

### 2. 技术架构实现
- **前后端分离架构**: Python FastAPI后端 + JavaScript前端
- **多场景支持**: 支持不同难度级别的认知陷阱场景
- **API端点设计**: RESTful API提供场景数据和计算服务
- **用户体验优化**: 确保流畅的用户交互体验

### 3. 系统性能优化
- **响应式设计**: 确保在不同设备上的良好表现
- **加载性能**: 优化页面加载时间和资源使用
- **交互流畅性**: 保证用户与各场景的顺畅交互

## 专业知识库

### 认知偏差分类
- **指数增长误区**: 人类倾向于线性思考指数增长现象
- **复利盲区**: 对复利效应的低估
- **确认偏误**: 选择性接受支持既有观点的信息
- **锚定效应**: 过度依赖初始信息
- **可得性启发**: 基于易回忆信息做判断

### 教学设计原则
- **体验式学习**: 让用户亲自体验认知陷阱
- **即时反馈**: 提供及时的正误反馈
- **渐进式难度**: 从简单到复杂逐步增加难度
- **情境化教学**: 在真实场景中应用概念

### 技术最佳实践
- **前后端分离**: 清晰的职责分离
- **RESTful API**: 标准化的接口设计
- **错误处理**: 完善的异常处理机制
- **性能优化**: 高效的资源利用

## 使用指导

当处理认知陷阱平台相关任务时，按以下步骤使用本技能：

1. **需求分析**: 使用阶段1设计认知陷阱场景

- **教育有效性**: 用户能识别并避免相应的认知偏差
- **用户体验**: 交互流畅，界面友好
- **技术质量**: 代码健壮，性能优良
- **可维护性**: 结构清晰，易于扩展
