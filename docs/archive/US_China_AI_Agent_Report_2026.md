| 项目 | 详情 |

| **安装方式及路径** | **Web**：chat.openai.com（浏览器直接访问）<br>**桌面端**：macOS/Windows 原生应用（从 openai.com 下载，安装至 `/Applications` 或 `%LOCALAPPDATA%`）<br>**移动端**：App Store / Google Play 搜索 "ChatGPT" |

| **核心差异化** | 全球最大用户基数；GPTs 自定义 Agent 生态；支持 GPT-5.6 Luna 等多模态旗舰模型；Code Interpreter（代码解释器）内置；Plugin/Function Call 生态成熟；企业版提供数据隔离与 SSO |

- 中国模型在 OpenRouter 上同样占主导：DeepSeek V4.1 Flash（日 3.9T tokens）、GLM 5.3 Flash（日 1.5T）等模型位列全球前10。

## 八、核心趋势与差异总结

### 8.1 技术趋势

1. **Agent 令牌消耗爆发**：OpenRouter 数据显示，2026年2月后 AI Agent 令牌使用量增长 14 倍（从 0.51T 到 7.3T tokens/月），AI 已成为自身最大的客户。
2. **终端原生 Agent 崛起**：Claude Code、OpenCode、Kimi Code 等终端 Agent 成为开发者标配，GitHub Stars 排名 OpenCode（209k）> Claude Code（147k）> Pi（108k）> Codex（90k）。
3. **IDE + Agent 融合**：Cursor、Devin Desktop、Qoder 等将 IDE 与 Agent 深度整合，Agent 不再独立于开发环境。
4. **多 Agent 并行编排**：Hermes Agent（300 sub-agent 并行）、Kimi K3（300 并行）、OpenCode（Build/Plan Agent 双模式）推动多 Agent 协作成为标配。
5. **ACP（Agent Client Protocol）标准化**：Devin Desktop 原生支持 ACP，允许多种 Agent（Codex、Claude Agent、OpenCode）在同一 IDE 中运行。

### 8.2 中美市场差异

| 维度 | 美国 | 中国 |
|---|---|---|
| **主导形态** | 终端 Agent + IDE 扩展（开发者驱动） | App + Web 平台（大众消费者驱动） |
| **最大玩家** | OpenAI（ChatGPT）、Anthropic（Claude）、GitHub（Copilot） | 字节跳动（豆包）、阿里（千问）、DeepSeek |
| **商业模式** | 订阅制（$20/月 Pro）+ API 按量计费 + 企业定制 | 免费 + 订阅（68-500元/月）+ 广告 + 生态变现 |
| **开源生态** | 成熟（OpenCode、Cline、Aider 等 MIT/Apache 协议） | 快速追赶（Qwen-Agent、DeepSeek 系列模型开源） |
| **部署偏好** | 本地优先（Ollama + 本地模型） | 云端优先（超级 App 生态绑定） |
| **数据主权** | 用户掌控（本地存储 + 可导出） | 平台掌控（云端存储，导出能力有限） |
| **合规重点** | GDPR、AI 安全评估 | 等保 2.0、数据安全法、算法备案 |

### 8.3 未来展望

- **中美脱钩下的技术分化**：美国在终端 Agent 和 IDE 生态领先；中国在移动端 Agent 和超级 App 集成领先。
- **开源 vs 闭源**：美国开源生态（OpenCode、Cline）与闭源巨头（OpenAI、Anthropic）并存；中国以平台闭源为主，开源模型（DeepSeek、GLM、Qwen）快速追赶。
- **Agent 经济规模**：OpenRouter 单平台月令牌消耗已达 67T（2026年8月），预计 2027年将进入 "AI 主要消费 AI" 的主流时代。
- **会话可移植性**：美国产品逐步标准化（JSONL/JSON/Markdown），中国产品尚缺乏统一导出标准，预计将随监管要求逐步改善。
