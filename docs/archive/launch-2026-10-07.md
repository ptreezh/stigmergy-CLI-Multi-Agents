## 一句话

**Stigmergy 是多个 AI CLI 工具的 orchestration layer：一次安装，所有 AI 命令行工具共享技能、共享上下文、自动路由。**

---

## 我们解决了什么问题

大多数开发者的电脑上，AI CLI 工具越来越多：

- Claude Code：深度推理
- Gemini CLI：多模态任务
- Qwen CLI：中文工作流
- Cursor / Copilot / Codex：IDE 内编码
- WorkBuddy / Marvis / Doubao：桌面 agent 工作流

**但它们互相不通信。**

你手动切换工具，复制粘贴上下文，反复解释同一个项目背景，把技能重复安装到 `~/.claude/skills`、`~/.qwen/skills`、`~/.cursor/skills`……

**Stigmergy 解决的就是这个 fragmentation。**

---

## 核心功能

### 1. 智能任务路由

```bash
stigmergy call "analyze this codebase and generate documentation"
```

Stigmergy 自动选择最适合的 AI 工具执行，必要时并行调用多个 agent。

### 2. 跨 CLI 技能共享

```bash
# 安装一次
stigmergy skill install owner/repo

# Claude、Qwen、Gemini、Cursor、Copilot、Codex 全部可用
```

不再为每个 CLI 单独维护 skill 副本。

### 3. 会话恢复与交接

```bash
stigmergy resume --session-id abc123
```

跨 CLI、跨 session 的记忆恢复。Claude 开始的工作，Qwen 可以无缝接手。

### 4. 远程 orchestration

```bash
stigmergy gateway --feishu --port 3000
```

通过飞书、Telegram、Slack、Discord 远程控制 AI agent 团队。

### 5. 桌面 agent 支持

WorkBuddy、Marvis、Doubao 等桌面 agent 的技能目录已纳入统一同步体系。

## 安装

```bash
npm install -g stigmergy@beta
stigmergy setup
```

`setup` 会自动扫描已安装的 AI CLI，部署跨工具 hooks，安装内置技能。

---

## 适用场景

### 场景 1：多工具协作开发

你同时使用 Claude Code 做架构设计，Qwen 做中文文档，Gemini 做代码审查。

```bash
stigmergy call "design user authentication, write docs in Chinese, review for security"
```

一个命令，三个 agent 协作完成。

### 场景 2：团队共享技能库

团队在多个项目中使用相同的 AI 技能。Stigmergy 中央技能目录确保技能版本统一：

```bash
~/.stigmergy/skills/           # 中央技能库
├── pdf/
├── react-best-practices/
└── api-design/
```

安装一次，所有 agent 自动同步。

### 场景 3：远程团队管理

出差时通过飞书/Telegram 控制本机的 AI agent 执行任务，结果自动推送回聊天窗口。
